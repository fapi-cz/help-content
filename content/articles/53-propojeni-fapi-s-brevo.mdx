Velmi užitečnou vlastností FAPI je schopnost propojení a spolupráce s nástroji pro e-mailový marketing. Díky tomu můžete kontaktní údaje zákazníka vyplněné v objednávce přenést do externí aplikace, kde je využijete pro rozesílku e-mailových kampaní.

V tomto článku si ukážeme, jak propojit FAPI s aplikací **Brevo**, dříve Sendinblue. V jednom účtu FAPI můžete mít více propojení s Brevo. U automatické akce potom vyberete konkrétní propojení a jeho seznam kontaktů.

## Nastavení propojení FAPI s Brevo (Sendinblue)

Při spolupráci dvou aplikací se ovládající aplikace (FAPI) přihlašuje do ovládané aplikace (Brevo) pomocí speciálního přístupového údaje, tzv. _API klíče_. Proto je nutné nejprve obě aplikace propojit.

### Získání API klíče z aplikace Brevo



V aplikaci Brevo přejděte v nastavení účtu do nabídky **SMTP & API**. Najdete ji pod tlačítkem/roletou vašeho profilu vpravo nahoře.

![Propojení FAPI s Brevo / Sendinblue](/assets/articles/077ae8b483fd2ace.png)

Na kartě **API keys** klikněte na **Generate a new API key**, klíč pojmenujte a potvrďte **Generate**. Klíč hned zkopírujte a bezpečně uložte — zobrazí se jen jednou. Podrobný postup najdete v [oficiálním návodu Brevo k API klíčům](https://developers.brevo.com/docs/api-key-authentication).

:::caution
API klíč chraňte stejně jako heslo. Neposílejte ho e-mailem ani ho nezveřejňujte na snímcích obrazovky.
:::

### Vložení API klíče do FAPI

1. Ve FAPI otevřete **Nastavení → <a href="https://web.fapi.cz/settings/connections" target="_blank" rel="noopener">Propojení aplikací</a>** a u položky **Brevo (Sendinblue)** klikněte na **Připojit**.
2. Volitelně vyplňte **Název propojení**, podle kterého poznáte připojený účet.
3. Do pole **Uživatelské jméno** vyplňte jméno, pod kterým se přihlašujete do příslušného účtu Brevo. Do pole **API klíč** vložte klíč vytvořený v tomto účtu.
4. Klikněte na **Uložit**.

![Formulář Brevo s označenými poli Název propojení, Uživatelské jméno a API klíč a tlačítkem Uložit.](/assets/multi-connections/brevo-connection.webp)

<a href="/assets/multi-connections/brevo-connection.webp" target="_blank" rel="noopener">Zobrazit formulář propojení s Brevo v plné velikosti</a>

Po uložení v **Nastavení → <a href="https://web.fapi.cz/settings/connections" target="_blank" rel="noopener">Propojení aplikací</a>** zkontrolujte příslušné propojení a stav **Připojeno**. Další účet Brevo přidejte jako další propojení ve stejném přehledu.

## Zápis a odebrání kontaktních údajů do/z Brevo (Sendinblue)

1. Otevřete **Prodej → <a href="https://web.fapi.cz/forms/?projectId=all" target="_blank" rel="noopener">Prodejní formuláře</a>**, vyberte formulář a přejděte na záložku **Akce**.
2. Vyberte událost a akci **přidat kontakt do Brevo**, případně **odebrat kontakt z Brevo**.
3. Vyberte konkrétní propojení a následně seznam kontaktů z tohoto propojení. Při změně propojení znovu zkontrolujte cílový seznam.
4. Uložte formulář a znovu jej otevřete. Ověřte, že akce používá správné propojení i seznam.

Než formulář použijete pro zákazníky, vyzkoušejte nastavenou událost s vlastním testovacím kontaktem a zkontrolujte výsledek ve správném seznamu v Brevo. Samotné propojení účtů ještě nenastavuje automatickou akci.

:::tip
Do aplikace Brevo můžete přenášet také údaje vyplněné zákazníkem do _vlastních polí_ objednávkového formuláře. Více informací najdete v článku <a href="/article/80-vlastni-pole" target="_blank" rel="noopener">Vlastní pole</a>.
:::

## Filtrování požadavků podle IP adres

Pokud v Brevo používáte omezení API podle IP adres, může být požadavek odmítnutý i se správným API klíčem. Postup správy povolených adres a volby autorizace popisuje [oficiální návod Brevo k zabezpečení podle IP adres](https://developers.brevo.com/docs/ip-security).

Před zapnutím blokování neznámých IP adres musí být povolené adresy serverů, ze kterých FAPI požadavky odesílá. Aktuální adresy pro nastavení si <a href="mailto:podpora@fapi.cz" target="_blank" rel="noopener">ověřte u podpory FAPI</a>.
