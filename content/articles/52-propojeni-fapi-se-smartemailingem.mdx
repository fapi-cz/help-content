Velmi užitečnou vlastností FAPI je schopnost propojení a spolupráce s nástroji pro e-mailový marketing. Díky tomu můžete kontaktní údaje zákazníka vyplněné v objednávce přenést do externí aplikace, kde je využijete pro rozesílku e-mailových kampaní.

V tomto článku si ukážeme, jak propojit FAPI s aplikací [SmartEmailing](https://www.smartemailing.cz/?a_box=21gse).

V jednom účtu FAPI můžete mít více samostatně pojmenovaných propojení se SmartEmailingem. U automatické akce pak vyberete konkrétní propojení a jeho cílový seznam kontaktů.

## Nastavení propojení FAPI se SmartEmailingem

Při spolupráci dvou aplikací se ovládající aplikace (FAPI) přihlašuje do ovládané aplikace (SmartEmailing) pomocí speciálního přístupového údaje, tzv. _API klíče_. Proto je nutné nejprve obě aplikace propojit.

Ve FAPI otevřete **Nastavení → <a href="https://web.fapi.cz/settings/connections" target="_blank" rel="noopener">Propojení aplikací</a>**. Pro nové propojení klikněte u položky **SmartEmailing** na **Připojit**. Volitelně vyplňte **Název propojení**, podle kterého připojený účet později poznáte, a přístupové údaje popsané níže. Existující propojení upravíte tlačítkem **Upravit** u jeho řádku.

![Formulář SmartEmailing s poli Název propojení, Uživatelské jméno, API klíč a tlačítkem Uložit](/assets/multi-connections/smartemailing-connection-20261109.webp)

<a href="/assets/multi-connections/smartemailing-connection-20261109.webp" target="_blank" rel="noopener">Zobrazit formulář v plné velikosti</a>

-   **UŽIVATELSKÉ JMÉNO** - vyplňte své uživatelské jméno, pod kterým se přihlašujete do SmartEmailingu.
-   **API KLÍČ** - vyplňte API klíč, který vygenerujete v aplikaci SmartEmailing v nabídce **Můj účet - API klíče**.

:::caution
Z bezpečnostních důvodů se API klíč zobrazí pouze bezprostředně po vygenerování. Při pozdější návštěvě stránky **Můj účet - API klíče** již API klíč v čitelné podobě nelze získat.
:::

Zadané údaje uložte tlačítkem **Uložit**. Další propojení přidáte ve stejném přehledu pomocí **Připojit**; původní propojení kvůli tomu nepřepisujte.

Po uložení se zobrazí informační hláška a u propojení se SmartEmailingem se objeví stav **Připojeno**.

## Zápis a odebrání kontaktních údajů do/ze SmartEmailingu

Automatické přidání, resp. odebrání kontaktních údajů uvedených v objednávce do/z vybraného seznamu SmartEmailingu nastavíte v prodejním formuláři na záložce **Akce**.

Použijte k tomu akci **přidat kontakt do SmartEmailingu**, resp. **odebrat kontakt ze SmartEmailingu**.

V nastavení akce vyberte konkrétní propojení a potom cílový seznam kontaktů z tohoto propojení. Při změně propojení znovu zkontrolujte zvolený seznam.

![Propojení FAPI se SmartEmailingem](/assets/articles/ef48de5d3a20ad18.png)

:::tip
Do aplikace SmartEmailing můžete přenášet také údaje vyplněné zákazníkem do  _vlastních polí_ objednávkového formuláře. Více informací najdete v článku <a href="/article/80-vlastni-pole" target="_blank" rel="noopener">Vlastní pole</a>.
:::



## Jaké údaje se přenáší do SmartEmailingu?

-   jméno
-   příjmení
-   telefon
-   adresa
-   hodnoty vlastních polí (vizte zelený boxík výše)
-   firma
-   ulice
-   město
-   psč
-   země
-   affil ID
-   údaje o obsahu objednávky (volitelně, vizte další blok níže)



## Odesílání dat o objednávce do SmartEmailingu

Odesílání dat o objednávce musí být povolené u konkrétního propojení. Otevřete **Nastavení → <a href="https://web.fapi.cz/settings/connections" target="_blank" rel="noopener">Propojení aplikací</a>**, vyberte jeho řádek a klikněte na **Upravit**.

![Propojení FAPI se SmartEmailingem](/assets/articles/d95385d1c1979ea7.png)

S objednávkou se přenášejí tato data:

Jméno eshopu: "FAPI", Variabilní symbol objednávky, emailová adresa klienta, status objednávky (objednáno, zaplaceno, stornováno), Datum objednávky, Datum zaplacení Dále se posílají i údaje o jednotlivých objednaných produktech: Název, Popis, Cena bez DPH, Cena s DPH, Měna, Množství, odkaz na prodejní formulář

Tyto údaje jsou odeslány při každé z těchto změn objednávky: Objednána, Zaplacena, Stornována.

:::tip
Stavy objednávek ve FAPI odpovídají stavům ve smartemailingu takto:

-   vystavená/issued = placed
-   zaplacená/paid = shipped
-   stornovaná/cancelled = canceled

případně pro neznámý stav je unknown
:::

:::danger
U objednávky **na splátky** se data přenesou až po úhradě první splátky.
:::



## Synchronizace starších dat

Pro nahrání starších objednávek otevřete **Nastavení → <a href="https://web.fapi.cz/settings/connections" target="_blank" rel="noopener">Propojení aplikací</a>**, vyberte příslušné propojení SmartEmailingu a v jeho nabídce zvolte **Synchronizovat objednávky**. U tohoto propojení musí být zapnuté odesílání dat o objednávkách. Synchronizace se vztahuje ke zvolenému propojení.
