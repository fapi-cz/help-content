FAPI nemá s CRM systémem **Raynet** přímou (nativní) integraci.

Propojení FAPI s CRM systémem Raynet je však možnédvěma způsoby:



## **1\. Přímé napojení přes API**

### Co budete potřebovat?

#### **API klíč ve FAPI**

-   Přihlaste se do FAPI
-   V pravém horním rohu klikněte na **Můj účet → API klíče**
-   Zde si vygenerujte svůj **API klíč**

:::tip
Použijte tuto FAPI nápovědu: [https://napoveda.fapi.cz/article/128-jak-ziskat-api-klic](/article/128-jak-ziskat-api-klic)
:::

![Propojení FAPI s Raynet CRM](/assets/articles/f5bdef8ca12d1184.png)

:::info
**📌 FAPI API dokumentace:**

👉 [https://web.fapi.cz/api-doc/](https://web.fapi.cz/api-doc/?utm_source=chatgpt.com)
:::



#### 2\. **API dokumentace Raynet CRM**

Raynet CRM má vlastní podrobné API, které umožňuje obousměrnou komunikaci.

<a href="https://raynet.cz/integrace/" target="_blank" rel="noopener noreferrer">https://raynet.cz/integrace/</a>



**Pomocí API si můžete naprogramovat např.:**

-   přenos kontaktů a zákazníků
-   automatický zápis faktur nebo objednávek
-   synchronizaci plateb a dalších dat



:::caution
📌 Pokud nemáte vývojáře, doporučujeme oslovit někoho se zkušeností s API integrací.
:::

## 2\. Propojení pomocí **Make (dříve Integromat)**



Pokud nemáte vývojáře, ale chcete FAPI a Raynet propojit bez programování, můžete využít nástroj [**Make.com**](/article/87-propojeni-aplikaci-pomoci-sluzby-integromat).

Oba nástroje (FAPI i Raynet) mají v Make vlastní moduly. Propojení je tak možné **klikáním bez kódu**.

#### Příklady využití:

-   po vystavení faktury ve FAPI vytvořit nový záznam v Raynetu
-   přidat nebo aktualizovat kontakt
-   synchronizovat nové objednávky

👉 Více o Make najdete na <a href="https://www.make.com/" target="_blank" rel="noopener noreferrer">https://www.make.com</a>

:::danger
