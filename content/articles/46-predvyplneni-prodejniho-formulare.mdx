V určitých případech může být užitečné automaticky předvyplnit vybraná pole prodejního formuláře FAPI na webové stránce konkrétními údaji klienta.

Jednou z možností jsou parametry v URL adrese stránky s prodejním formulářem. Vkládejte je do adresy stránky, ne do URL vkládaného skriptu. Pro vlastní JavaScript můžete použít také programové předvyplnění.

**Celý videonávod máte k dispozici zde:**

<Video src="https://www.youtube.com/embed/p5E8ct0i9Zc" />

:::caution
Výsledek předvyplnění ověřujte na stránce s vloženým formulářem, ne pouze v editoru FAPI.
:::

## Jaké údaje lze předvyplnit?

Pro předvyplnění prodejního formuláře je možné použít následující parametry:

- **fapi-form-name\=** (Jméno)
- **fapi-form-surname\=** (Příjmení)
- **fapi-form-email\=** (E-mailová adresa)
- **fapi-form-mobil**\= (Mobil)
- **fapi-form-street**\= (Ulice)
- **fapi-form-city\=** (Město)
- **fapi-form-postcode\=** (PSČ)
- **fapi-form-state\=** (Stát)
- **fapi-form-company**\= (Firma)
- **fapi-form-ic**\= (IČ)
- **fapi-form-dic\=** (DIČ)
- **fapi-form-notes\=** (Poznámka)
- **fapi-form-discountCode\=** (Slevový kód)
- **fapi-form-customField-\{id}** (Vlastní pole)
- **fapi-form-item-\{product_code}\=1** (předvybrání /\=1/ nebo vypnutí /\=0/ označení produktu) 
- **fapi-form-item-count-\{product_code}\=10** (Nastavení počet produktů k zakoupení, pouze v případě že se ve formuláři dá počet zakoupených produktů měnit) 
- **fapi-form-repayment\=1** (předvybrání /\=1/ nebo vypnutí /\=0/ splátek)

:::caution
Předvyplněný slevový kód se automaticky aktivuje, takže v objednávkovém formuláři se zobrazuje cena se započtením slevy.

U předvyplnění produktu se místo  `{product_code}`    vloží kód produktu (který je v přehledu položek v prvním sloupci), pokud chcete i předvyplnit počet kusů  `fapi-form-item-count-{product_code}=5`    (nastavení pro 5ks)
:::

## Formát zápisu

Parametry se do URL adresy stránky vkládají spolu s hodnotou, která se má předvyplnit do příslušného pole prodejního formuláře.

Obecný formát zápisu je následující:

```text
?název_parametru_1=hodnota_parametru_1&název_parametru_2=hodnota_parametru_2&...
```

:::caution
Parametry se připojují na konec URL adresy pomocí znaku "?". Pokud je v adrese tento znak již obsažen, použije se k připojení parametrů znak "&". Více parametrů se od sebe odděluje rovněž pomocí znaku "&"‘.
:::

## Příklady použití

Předvyplnění e-mailové adresy, jména a příjmení klienta a poznámky (Jan Malý, [jan.maly@seznam.cz](mailto\:jan.maly@seznam.cz), VIP):

```text
?fapi-form-email=jan.maly@seznam.cz&fapi-form-name=Jan&fapi-form-surname=Malý&fapi-form-notes=VIP
```

Předvyplnění státu (Dánsko):

```text
?fapi-form-state=DK
```

:::caution
Pro hodnotu státu (parametr **fapi-form-state**) se používá standardizovaný kód _Alpha-2_ (dvoupísmenná zkratka) podle mezinárodní [normy ISO 3166-1](https://en.wikipedia.org/wiki/ISO_3166-1).
:::

Předvyplnění vlastního pole (sobota):

```text
?fapi-form-customField-20=sobota
```

:::caution
Parametr **fapi-form-customField** je potřeba vždy doplnit o ID konkrétního vlastního pole, které získáte z URL adresy.
:::

## Programové vyplnění prodejního formuláře

Pokud máte zákaznické údaje k dispozici ve svém webu, můžete je předat formuláři metodou `prefillCustomer`. Není potřeba měnit jednotlivá HTML pole ani ručně vyvolávat jejich události. S úpravou JavaScriptu vám může pomoci správce webu.

1. Na stránku vložte následující kód **před kód prodejního formuláře**. Ukázkové údaje nahraďte údaji, které chcete předvyplnit.
2. Za něj vložte běžný <a href="/article/75-vlozeni-prodejniho-formulare-na-web" target="_blank" rel="noopener">HTML kód prodejního formuláře</a>.
3. Stránku uložte, otevřete ji mimo editor a zkontrolujte vyplněná pole. Zákazník může údaje před objednáním upravit.

```html
<script>
  document.addEventListener('fapiFormMounted', function (event) {
    event.detail.api.prefillCustomer({
      email: 'zakaznik@example.com',
      company: 'Ukázková firma',
      ic: '12345679'
    });
  });
</script>
```

Událost `fapiFormMounted` vzniká při připojení každého formuláře. Uvedená ukázka proto vyplní každý formulář vložený na stránce. Předvyplněná firma nebo IČ zobrazí firemní údaje. **Klíče, které metodě nepředáte, se nemění**. Neprázdné hodnoty v `fapi-form-data` nebo URL parametrech `fapi-form-…` mají přednost před údaji předanými metodě.

**Další formulář na vlastní děkovací stránce**

Pokud chcete po objednávce nabídnout další nákup bez opakovaného zadávání kontaktu, může zákaznické údaje předat **FAPI SDK**, tedy skript pro práci s údaji objednávky:

```html
<script src="https://form.fapi.cz/js/sdk/fapi.js"></script>
```

Nejprve připravte <a href="/article/338-zastupne-symboly-v-e-mailech-a-dekovaci-strance#Vlastn-extern-dkovac-strnka-WNtpu" target="_blank" rel="noopener">vlastní děkovací stránku</a> s HTTPS, SDK a předáním identifikátoru objednávky do URL. Na stránku musí přijít parametr `path` původní objednávky. Správce webu zajistí, aby byly požadované formuláře připojené před zpracováním dat v SDK. To je předvyplní **jednou**, včetně více instancí stejného formuláře. Později přidaný formulář se automaticky nedoplní. Samotný vkládací kód formuláře údaje předchozí objednávky nenačítá.

Přebírají se kontaktní a fakturační údaje; samostatná doručovací adresa jen tehdy, pokud ji předchozí objednávka má a nový formulář ji povoluje. Produkty, způsob platby, poznámka a souhlasy patří k nové objednávce a tímto přenosem se nevyplní. Odkaz s parametrem `path` nesdílejte veřejně, protože zpřístupňuje údaje objednávky.

## Zrušení předvyplnění prvního produktu

Otevřete nastavení svého formuláře: <a href="https://web.fapi.cz/forms/" target="_blank" rel="noopener">Prodejní formuláře</a> → **2. Položky a ceny**. Zapněte **Vypnout předvyplnění prvního produktu** a formulář uložte.

## Vlastní technické údaje bez viditelného pole

Pokud chcete s objednávkou uložit například označení varianty nabídky, použijte `setCustomTracking`. Údaj se uloží k objednávce do `tracking.custom`. Metoda nevytváří viditelné <a href="/article/80-vlastni-pole" target="_blank" rel="noopener">vlastní pole</a> ve formuláři ani hodnotu v `custom_fields` faktury. Úpravu JavaScriptu svěřte správci webu.

1. Na stránku s vloženým formulářem přidejte následující kód **před vkládací kód formuláře**. Ukázkový klíč a hodnotu nahraďte svými technickými údaji:

   ```html
   <script>
     document.addEventListener('fapiFormMounted', function (event) {
       event.detail.api.setCustomTracking({
         campaign_variant: 'varianta-a'
       });
     });
   </script>
   ```

   Ukázka nastaví údaje každému formuláři připojenému na stránce. Pro jeden konkrétní formulář přidejte do obsluhy události podmínku podle `event.detail.formPath`.
2. Stránku uložte a otevřete mimo editor. Po připojení formuláře lze nastavené hodnoty zkontrolovat metodou `getCustomTracking()` na jeho API. Údaje nastavte znovu při každém načtení stránky, vždy před odesláním objednávky.
3. Vytvořte <a href="/article/90-testovani-celeho-online-prodejniho-procesu" target="_blank" rel="noopener">testovací objednávku</a>. Pro načtení uložených údajů použijte **na serveru autentizované** <a href="/article/84-ovladani-fapi-pres-api-rozhrani" target="_blank" rel="noopener">API FAPI</a>, konkrétně seznam objednávek:

   ```text
   GET https://api.fapi.cz/orders?invoice=ID_FAKTURY
   ```

   `ID_FAKTURY` nahraďte interním ID faktury přímo přiřazené objednávce, ne jejím číslem ani ID objednávky. Ve vráceném poli `orders` vyberte odpovídající objednávku a zkontrolujte `tracking.custom.campaign_variant`. V ukázce má hodnotu `varianta-a`.

:::caution
Podporované vstupní hodnoty jsou text (`string`), číslo (`number`), `boolean` a `null`. Nepředávejte vnořené objekty ani pole. Další volání `setCustomTracking` doplňuje nebo přepisuje jednotlivé klíče; pro čtení slouží `getCustomTracking()`.

Klíče `browser`, `facebook`, `chatgpt_ads`, `tiktok`, `pinterest`, `ga4`, `fapi`, `microsoft`, `utm` a `custom` jsou rezervované a `setCustomTracking` je nepřijme jako vlastní klíč.

Nejde o bezpečné úložiště tajných údajů: data předává JavaScript v prohlížeči. Nevkládejte sem hesla, přístupové tokeny ani API klíče. API klíč pro serverové načtení objednávky nedávejte do kódu veřejné stránky.
:::

Pro tato technická data čtěte **objednávku (`orders`)**, nikoli jen fakturu (`invoices`). Odpověď API s fakturou a jejím `custom_fields` je jiný datový výstup. Filtr `invoice` vyhledává přímou vazbu objednávky na dané ID dokladu; navazující doklad se automaticky nepřevádí na původní objednávku.
