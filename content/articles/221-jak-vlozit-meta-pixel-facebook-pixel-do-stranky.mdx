## **Získání Meta Pixelu**

1.  Otevřte **Meta Business Manager \> Nastavení firmy**
2.  **V nástrojích \> Správce událostí (Events Manager)**
3.  Zdroje dat \> Zvolte nebo vytvořte **Meta Pixel**
4.  Aktivní integrace \> Spravovat integrace \> Meta Pixel
5.  Zkopírujte si svůj **Pixel ID** nebo celý kód

:::caution
Pro ruční vložení na web kopírujte **základní kód Pixelu** (ne jen ID).



Meta vás občas automaticky přepne do jiné firmy/účtu. Před kopírováním kódu si zkontrolujte, že jste ve správném Business účtu a u správného Pixelu.
:::

## **Kam Meta Pixel vložit**

Pixel se vkládá **do hlavičky webu (\<head\>)** **na všech stránkách**, kde chcete měřit chování uživatelů.

:::caution
**Doporučení**

Meta Pixel mějte nasazený na webu i v případě, že používáte Conversion API (CAPI). Pixel na webu pomáhá Metě správně párovat návštěvy a měření/optimalizace pak fungují lépe.
:::

## **Varianty nasazení Meta Pixelu**

### **✅ Varianta A: Přímé vložení do HTML**

Vlož kód pixelu **před \</head\>**:

```text
<!-- Meta Pixel Code -->
<script>
!function(f,b,e,v,n,t,s)
{if(f.fbq)return;n=f.fbq=function(){n.callMethod?
n.callMethod.apply(n,arguments):n.queue.push(arguments)};
if(!f._fbq)f._fbq=n;n.push=n;n.loaded=!0;n.version='2.0';
n.queue=[];t=b.createElement(e);t.async=!0;
t.src=v;s=b.getElementsByTagName(e)[0];
s.parentNode.insertBefore(t,s)}(window, document,'script',
'https://connect.facebook.net/en_US/fbevents.js');
fbq('init', 'PIXEL_ID');
fbq('track', 'PageView');
</script>
<!-- End Meta Pixel Code -->
```

:::danger
**PIXEL\_ID** nahraď te **svým ID**.
:::
